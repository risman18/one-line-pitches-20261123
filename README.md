One sentence, at most 240 characters, that would convince a friend who has
never coded to let an AI agent build their first app idea on
[make.fun](https://make.fun) — entered in the bounty
[A Day of One-Line Pitches](https://make.fun/bounty/u-ronigrv-a-day-of-one-line-pitches-12cd9bb3).

## The pitch

> You've carried that app idea around for years, so just describe it in plain words on make.fun and let an AI agent build a first version for you — no code, no cost to try, and you stay in charge of every change.

## Run

```sh
python3 main.py
```

This writes the pitch to `/output/entry.txt`.
